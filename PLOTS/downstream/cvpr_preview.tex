\section{Plot conventions}
Each task uses two independently scaled logarithmic accuracy axes. The 5\% label-budget groups use the left axis and the 1\% groups use the right axis. The bounds include every error bar, with a small margin beyond the lowest benchmark and full-data reference. The x-axis values denote percentages of the pretraining data; the label-budget annotations denote percentages of labeled downstream data.
